# JResume – Resume Builder A web application for creating, editing, and exporting professional resumes with ease. JResume empowers users to quickly craft polished resumes using customizable templates, an intuitive editor, and instant PDF export capabilities. --- ## Features - **User-Friendly Resume Editor** Add, edit, and organize your personal, educational, and professional details in a guided interface. - **Customizable Templates** Choose from multiple professionally designed resume templates. - **Section Reordering** Easily reorder sections (Experience, Education, Skills, etc.) to suit your needs. - **Instant Preview** See live updates as you edit your resume. - **Export as PDF** Download your finished resume as a high-quality PDF file. - **Save and Load** Save your progress locally and reload it anytime. - **Responsive Design** Works seamlessly on desktop and mobile browsers. --- ## Screenshots > _Screenshots coming soon!_ --- ## Installation ### Prerequisites - [Node.js](https://nodejs.org/) (version 14 or later recommended) - npm (comes with Node.js) or [Yarn](https://yarnpkg.com/) ### Steps 1. **Clone the Repository** ```bash git clone https://github.com/JiyauddinSaiyad/resume-builder.git cd resume-builder ``` 2. **Install Dependencies** ```bash npm install # or yarn install ``` 3. **Start the Development Server** ```bash npm start # or yarn start ``` The app opens in your default browser at `http://localhost:3000`. --- ## Usage 1. Open the application in your browser. 2. Enter your personal information, education, work experience, skills, and other relevant details. 3. Choose a resume template from the available options. 4. Reorder sections as desired by dragging and dropping. 5. Preview your resume in real-time. 6. Click the “Export as PDF” button to download your resume. 7. Optionally, save your progress and load it later to continue editing. --- ## Deployment To create a production build for deployment: ```bash npm run build # or yarn build ``` This outputs optimized static files in the `build` directory. You can deploy the contents of the `build` directory to any static hosting provider, such as: - [Netlify](https://www.netlify.com/) - [Vercel](https://vercel.com/) - [GitHub Pages](https://pages.github.com/) --- ## Contributing We welcome contributions.
